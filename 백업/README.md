# 백업 폴더

**여기에 백업 파일을 두지 마세요.**

이 저장소는 공개(public)입니다. 관리자 콘솔 `💾 백업`으로 내려받은 파일에는
이벤트 응모자의 이름·소속·연락처와, 익명 의견을 쓴 사람을 가려낼 수 있는
작성자 번호가 들어 있습니다. 저장소에 올리면 그대로 공개됩니다.

내려받은 백업은 **업무용 PC나 부서 공유 폴더** 등 저장소 바깥에 보관하세요.
`.gitignore` 로 `백업/하위폴더/` 와 `새소리단_백업_*.json` 은 자동으로 제외됩니다.

### 지난 일

2026-11-19 사고 직후, 남아 있던 자료를 급히 이 폴더에 내려받아 올렸습니다.
나중에 확인해 보니 `posts.json`(실명)과 `opinions.json`(익명 별명)이
같은 `author_id` 로 이어져, **익명 의견 작성자 2명이 실명과 연결**되는
상태였습니다. 해당 파일은 모두 삭제했습니다.
