Supabase 연결 설정

Supabase 프로젝트의 주소와 anon public 키를 입력하세요. 대시보드 > Project Settings > API 에서 확인할 수 있습니다.

anon 키는 공개되어도 되는 키입니다. 실제 권한은 데이터베이스의 RLS 정책이 결정하므로, 이 키를 알아도 남의 영수증은 볼 수 없습니다.

아직 준비 전이라면 standalone.html 을 열어 서버 없이 사용할 수 있습니다.
